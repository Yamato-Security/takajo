# Acerca de Takajō

Takajō (鷹匠), creado por [Yamato Security](https://github.com/Yamato-Security), es un analizador forense rápido para los resultados de [Hayabusa](https://github.com/Yamato-Security/hayabusa) escrito en [Nim](https://nim-lang.org/).
Takajō significa ["Halconero"](https://en.wikipedia.org/wiki/Falconry) en japonés y fue elegido porque analiza las "capturas" (resultados) de Hayabusa.
