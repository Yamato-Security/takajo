# Sobre o Takajō

O Takajō (鷹匠), criado pela [Yamato Security](https://github.com/Yamato-Security), é um analisador forense rápido para resultados do [Hayabusa](https://github.com/Yamato-Security/hayabusa) escrito em [Nim](https://nim-lang.org/).
Takajō significa ["Falcoeiro"](https://en.wikipedia.org/wiki/Falconry) em japonês e foi escolhido por analisar as "capturas" (resultados) do Hayabusa.
