# เกี่ยวกับ Takajō

Takajō (鷹匠) สร้างขึ้นโดย [Yamato Security](https://github.com/Yamato-Security) เป็นเครื่องมือวิเคราะห์ฟอเรนสิกที่รวดเร็วสำหรับผลลัพธ์ของ [Hayabusa](https://github.com/Yamato-Security/hayabusa) ซึ่งเขียนด้วย [Nim](https://nim-lang.org/)
Takajō มีความหมายว่า ["ผู้ฝึกเหยี่ยว"](https://en.wikipedia.org/wiki/Falconry) ในภาษาญี่ปุ่น และถูกเลือกมาเนื่องจากมันวิเคราะห์ "สิ่งที่จับได้" (ผลลัพธ์) ของ Hayabusa
