# Takajō အကြောင်း

Takajō (鷹匠) သည် [Yamato Security](https://github.com/Yamato-Security) မှ ဖန်တီးထားသော၊ [Nim](https://nim-lang.org/) ဖြင့်ရေးသားထားသည့် [Hayabusa](https://github.com/Yamato-Security/hayabusa) ရလဒ်များအတွက် မြန်ဆန်သော forensics ခွဲခြမ်းစိတ်ဖြာရေး tool တစ်ခုဖြစ်သည်။
Takajō ၏ အဓိပ္ပာယ်မှာ ဂျပန်ဘာသာဖြင့် ["Falconer"](https://en.wikipedia.org/wiki/Falconry) ဖြစ်ပြီး၊ ၎င်းသည် Hayabusa ၏ "catches" (ရလဒ်များ) ကို ခွဲခြမ်းစိတ်ဖြာသောကြောင့် ဤအမည်ကို ရွေးချယ်ခဲ့ခြင်းဖြစ်သည်။
