# حول Takajō

Takajō (鷹匠)، الذي أنشأته [Yamato Security](https://github.com/Yamato-Security)، هو محلل جنائي سريع لنتائج [Hayabusa](https://github.com/Yamato-Security/hayabusa) مكتوب بلغة [Nim](https://nim-lang.org/).
تعني كلمة Takajō ["البيّاز"](https://en.wikipedia.org/wiki/Falconry) باللغة اليابانية، وقد تم اختيارها لأنه يحلل "صيد" Hayabusa (النتائج).
