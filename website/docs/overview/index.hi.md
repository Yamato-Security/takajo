# Takajō के बारे में

Takajō (鷹匠), [Yamato Security](https://github.com/Yamato-Security) द्वारा बनाया गया, [Hayabusa](https://github.com/Yamato-Security/hayabusa) परिणामों के लिए एक तेज़ फोरेंसिक विश्लेषक है जो [Nim](https://nim-lang.org/) में लिखा गया है।
Takajō का जापानी में अर्थ ["Falconer"](https://en.wikipedia.org/wiki/Falconry) है और इसे इसलिए चुना गया क्योंकि यह Hayabusa के "शिकार" (परिणामों) का विश्लेषण करता है।
