# Takajō 소개

[Yamato Security](https://github.com/Yamato-Security)가 만든 Takajō(鷹匠)는 [Nim](https://nim-lang.org/)으로 작성된 [Hayabusa](https://github.com/Yamato-Security/hayabusa) 결과를 위한 빠른 포렌식 분석 도구입니다.
Takajō는 일본어로 ["매잡이(Falconer)"](https://en.wikipedia.org/wiki/Falconry)를 뜻하며, Hayabusa의 "포획물"(결과)을 분석한다는 의미에서 선택되었습니다.
