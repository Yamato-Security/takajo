# Tentang Takajō

Takajō (鷹匠), dibuat oleh [Yamato Security](https://github.com/Yamato-Security), adalah penganalisis forensik cepat untuk hasil [Hayabusa](https://github.com/Yamato-Security/hayabusa) yang ditulis dalam [Nim](https://nim-lang.org/).
Takajō berarti ["Pawang Elang"](https://en.wikipedia.org/wiki/Falconry) dalam bahasa Jepang dan dipilih karena menganalisis "tangkapan" (hasil) Hayabusa.
