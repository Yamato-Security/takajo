# À propos de Takajō

Takajō (鷹匠), créé par [Yamato Security](https://github.com/Yamato-Security), est un analyseur forensique rapide pour les résultats de [Hayabusa](https://github.com/Yamato-Security/hayabusa) écrit en [Nim](https://nim-lang.org/).
Takajō signifie ["Fauconnier"](https://en.wikipedia.org/wiki/Falconry) en japonais et a été choisi car il analyse les « prises » (résultats) de Hayabusa.
