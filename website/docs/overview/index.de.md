# Über Takajō

Takajō (鷹匠), erstellt von [Yamato Security](https://github.com/Yamato-Security), ist ein schneller Forensik-Analyzer für [Hayabusa](https://github.com/Yamato-Security/hayabusa)-Ergebnisse, geschrieben in [Nim](https://nim-lang.org/).
Takajō bedeutet ["Falkner"](https://en.wikipedia.org/wiki/Falconry) auf Japanisch und wurde gewählt, da es Hayabusas "Fänge" (Ergebnisse) analysiert.
