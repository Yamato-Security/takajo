# Про Takajō

Takajō (鷹匠), створений [Yamato Security](https://github.com/Yamato-Security), — це швидкий криміналістичний аналізатор для результатів [Hayabusa](https://github.com/Yamato-Security/hayabusa), написаний мовою [Nim](https://nim-lang.org/).
Takajō японською означає ["Сокольник"](https://en.wikipedia.org/wiki/Falconry) і був обраний, оскільки він аналізує "здобич" Hayabusa (результати).
