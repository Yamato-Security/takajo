# Git cloning

အောက်ပါ command ဖြင့် repository ကို git clone လုပ်ပြီး source code မှ binary ကို compile လုပ်နိုင်ပါသည်။

> သတိပေးချက်- repository ၏ main branch သည် development ရည်ရွယ်ချက်အတွက်ဖြစ်သောကြောင့် တရားဝင်ထုတ်ပြန်ခြင်းမပြုရသေးသော feature အသစ်များကို သင်အသုံးပြုနိုင်ပါသည်၊ သို့သော် bug များရှိနိုင်သောကြောင့် တည်ငြိမ်မှုမရှိ (unstable) ဟု သတ်မှတ်ပါ။

`git clone https://github.com/Yamato-Security/takajo.git`
