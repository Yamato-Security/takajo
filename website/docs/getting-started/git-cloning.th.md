# การ Clone ด้วย Git

คุณสามารถ clone repository ด้วย git โดยใช้คำสั่งต่อไปนี้ และคอมไพล์ไบนารีจากซอร์สโค้ดได้:

> คำเตือน: main branch ของ repository มีไว้เพื่อวัตถุประสงค์ในการพัฒนา ดังนั้นคุณอาจเข้าถึงฟีเจอร์ใหม่ที่ยังไม่ได้เปิดตัวอย่างเป็นทางการได้ อย่างไรก็ตาม อาจมีบั๊กอยู่ จึงควรพิจารณาว่ายังไม่เสถียร

`git clone https://github.com/Yamato-Security/takajo.git`
