# Git cloning

आप निम्नलिखित कमांड के साथ रिपॉज़िटरी को git clone कर सकते हैं और सोर्स कोड से बाइनरी कंपाइल कर सकते हैं:

> चेतावनी: रिपॉज़िटरी की मुख्य ब्रांच विकास उद्देश्यों के लिए है इसलिए आप ऐसी नई सुविधाओं तक पहुँच सकते हैं जो अभी आधिकारिक रूप से जारी नहीं की गई हैं, हालाँकि, इसमें बग हो सकते हैं इसलिए इसे अस्थिर मानें।

`git clone https://github.com/Yamato-Security/takajo.git`
