# Contribución y Soporte

## Contribución

Nos encantaría recibir cualquier forma de contribución. Las pull requests, la creación de reglas y los registros evtx de muestra son lo mejor, pero las solicitudes de funciones, notificarnos de errores, etc... también son muy bienvenidas.

Como mínimo, si te gusta nuestra herramienta, ¡por favor danos una estrella en Github y muestra tu apoyo!

## Envío de Errores

Por favor envía cualquier error que encuentres [aquí.](https://github.com/Yamato-Security/takajo/issues/new?assignees=&labels=bug&template=bug_report.md&title=%5Bbug%5D)
Este proyecto se mantiene actualmente de forma activa y estaremos encantados de corregir cualquier error reportado.

Si encuentras algún problema (falsos positivos, errores, etc...) con Hayabusa, por favor repórtalo en la página de issues de github de hayabusa [aquí](https://github.com/Yamato-Security/takajo/issues/new?assignees=&labels=bug&template=bug_report.md&title=%5Bbug%5D).

Si encuentras algún problema (falsos positivos, errores, etc...) con las reglas de Hayabusa, por favor repórtalo en la página de issues de github de hayabusa-rules [aquí](https://github.com/Yamato-Security/hayabusa-rules/issues/new).

Si encuentras algún problema (falsos positivos, errores, etc...) con las reglas de Sigma, por favor repórtalo en la página de issues de github de SigmaHQ original [aquí](https://github.com/SigmaHQ/sigma/issues).
