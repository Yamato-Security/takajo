# Kontribusi & Dukungan

## Kontribusi

Kami sangat menghargai segala bentuk kontribusi. Pull request, pembuatan aturan, dan contoh log evtx adalah yang terbaik, tetapi permintaan fitur, memberi tahu kami tentang bug, dll... juga sangat kami sambut.

Setidaknya, jika Anda menyukai alat kami, mohon beri kami bintang di Github dan tunjukkan dukungan Anda!

## Pengiriman Bug

Mohon kirimkan bug apa pun yang Anda temukan [di sini.](https://github.com/Yamato-Security/takajo/issues/new?assignees=&labels=bug&template=bug_report.md&title=%5Bbug%5D)
Proyek ini saat ini aktif dipelihara dan kami dengan senang hati memperbaiki bug apa pun yang dilaporkan.

Jika Anda menemukan masalah apa pun (false positive, bug, dll...) dengan Hayabusa, mohon laporkan ke halaman issue github hayabusa [di sini](https://github.com/Yamato-Security/takajo/issues/new?assignees=&labels=bug&template=bug_report.md&title=%5Bbug%5D).

Jika Anda menemukan masalah apa pun (false positive, bug, dll...) dengan aturan Hayabusa, mohon laporkan ke halaman issue github hayabusa-rules [di sini](https://github.com/Yamato-Security/hayabusa-rules/issues/new).

Jika Anda menemukan masalah apa pun (false positive, bug, dll...) dengan aturan Sigma, mohon laporkan ke halaman issue github SigmaHQ upstream [di sini](https://github.com/SigmaHQ/sigma/issues).
