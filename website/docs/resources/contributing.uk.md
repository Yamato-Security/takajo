# Внесок та підтримка

## Внесок

Ми будемо раді будь-якій формі внеску. Pull-запити, створення правил та зразки журналів evtx є найкращими, але запити на нові функції, повідомлення про помилки тощо також дуже вітаються.

Як мінімум, якщо вам подобається наш інструмент, будь ласка, поставте нам зірку на Github і покажіть свою підтримку!

## Надсилання повідомлень про помилки

Будь ласка, надсилайте будь-які знайдені вами помилки [сюди.](https://github.com/Yamato-Security/takajo/issues/new?assignees=&labels=bug&template=bug_report.md&title=%5Bbug%5D)
Цей проєкт наразі активно підтримується, і ми будемо раді виправити будь-які повідомлені помилки.

Якщо ви виявите будь-які проблеми (хибні спрацювання, помилки тощо) з Hayabusa, будь ласка, повідомте про них на сторінці issues у github проєкту hayabusa [тут](https://github.com/Yamato-Security/takajo/issues/new?assignees=&labels=bug&template=bug_report.md&title=%5Bbug%5D).

Якщо ви виявите будь-які проблеми (хибні спрацювання, помилки тощо) з правилами Hayabusa, будь ласка, повідомте про них на сторінці issues у github проєкту hayabusa-rules [тут](https://github.com/Yamato-Security/hayabusa-rules/issues/new).

Якщо ви виявите будь-які проблеми (хибні спрацювання, помилки тощо) з правилами Sigma, будь ласка, повідомте про них на сторінці issues у github вихідного проєкту SigmaHQ [тут](https://github.com/SigmaHQ/sigma/issues).
