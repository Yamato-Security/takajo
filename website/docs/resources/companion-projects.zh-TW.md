# 相關專案

* [EnableWindowsLogSettings](https://github.com/Yamato-Security/EnableWindowsLogSettings) - 用於正確啟用 Windows 事件日誌的文件與指令碼。
* [Hayabusa](https://github.com/Yamato-Security/hayabusa) - 針對 Windows 事件日誌、以 sigma 為基礎的威脅獵捕與快速鑑識時間軸產生器。
* [Hayabusa Rules](https://github.com/Yamato-Security/hayabusa-rules) - hayabusa 的偵測規則。
* [Hayabusa Sample EVTXs](https://github.com/Yamato-Security/hayabusa-sample-evtx) - 用於測試 hayabusa/sigma 偵測規則的範例 evtx 檔案。
* [WELA (Windows Event Log Analyzer)](https://github.com/Yamato-Security/WELA) - 以 PowerShell 撰寫的 Windows 事件日誌分析器。
