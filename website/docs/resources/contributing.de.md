# Mitwirken & Support

## Beitrag

Wir freuen uns über jede Form von Beitrag. Pull Requests, Regelerstellung und Beispiel-evtx-Logs sind am besten, aber auch Funktionswünsche, Hinweise auf Fehler usw. sind sehr willkommen.

Wenn Ihnen unser Tool gefällt, geben Sie uns zumindest einen Stern auf Github und zeigen Sie Ihre Unterstützung!

## Fehlermeldung

Bitte melden Sie alle von Ihnen gefundenen Fehler [hier.](https://github.com/Yamato-Security/takajo/issues/new?assignees=&labels=bug&template=bug_report.md&title=%5Bbug%5D)
Dieses Projekt wird derzeit aktiv gepflegt und wir beheben gerne alle gemeldeten Fehler.

Wenn Sie Probleme (False Positives, Fehler usw.) mit Hayabusa finden, melden Sie diese bitte auf der Github-Issues-Seite von Hayabusa [hier](https://github.com/Yamato-Security/takajo/issues/new?assignees=&labels=bug&template=bug_report.md&title=%5Bbug%5D).

Wenn Sie Probleme (False Positives, Fehler usw.) mit Hayabusa-Regeln finden, melden Sie diese bitte auf der Github-Issues-Seite von hayabusa-rules [hier](https://github.com/Yamato-Security/hayabusa-rules/issues/new).

Wenn Sie Probleme (False Positives, Fehler usw.) mit Sigma-Regeln finden, melden Sie diese bitte auf der vorgelagerten Github-Issues-Seite von SigmaHQ [hier](https://github.com/SigmaHQ/sigma/issues).
