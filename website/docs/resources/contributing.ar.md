# المساهمة والدعم

## المساهمة

نرحب بأي شكل من أشكال المساهمة. طلبات السحب (Pull requests) وإنشاء القواعد وعينات سجلات evtx هي الأفضل، ولكن طلبات الميزات وإبلاغنا بالأخطاء وما إلى ذلك... مرحب بها أيضًا.

على أقل تقدير، إذا أعجبتك أداتنا فيرجى منحنا نجمة على Github وإظهار دعمك!

## إبلاغ عن الأخطاء

يرجى إرسال أي أخطاء تجدها [هنا.](https://github.com/Yamato-Security/takajo/issues/new?assignees=&labels=bug&template=bug_report.md&title=%5Bbug%5D)
يتم حاليًا صيانة هذا المشروع بنشاط ويسعدنا إصلاح أي أخطاء يتم الإبلاغ عنها.

إذا وجدت أي مشكلات (إيجابيات كاذبة، أخطاء، وما إلى ذلك...) مع Hayabusa، فيرجى الإبلاغ عنها إلى صفحة مشكلات hayabusa على github [هنا](https://github.com/Yamato-Security/takajo/issues/new?assignees=&labels=bug&template=bug_report.md&title=%5Bbug%5D).

إذا وجدت أي مشكلات (إيجابيات كاذبة، أخطاء، وما إلى ذلك...) مع قواعد Hayabusa، فيرجى الإبلاغ عنها إلى صفحة مشكلات hayabusa-rules على github [هنا](https://github.com/Yamato-Security/hayabusa-rules/issues/new).

إذا وجدت أي مشكلات (إيجابيات كاذبة، أخطاء، وما إلى ذلك...) مع قواعد Sigma، فيرجى الإبلاغ عنها إلى صفحة مشكلات SigmaHQ الأصلية على github [هنا](https://github.com/SigmaHQ/sigma/issues).
