# ပံ့ပိုးကူညီခြင်းနှင့် အထောက်အပံ့

## ပံ့ပိုးကူညီမှု

ကျွန်ုပ်တို့သည် မည်သည့်ပုံစံဖြင့်မဆို ပံ့ပိုးကူညီမှုကို နှစ်သက်ပါသည်။ Pull request များ၊ rule ဖန်တီးခြင်းနှင့် နမူနာ evtx log များသည် အကောင်းဆုံးဖြစ်သော်လည်း feature တောင်းဆိုမှုများ၊ bug များကို ကျွန်ုပ်တို့အား အသိပေးခြင်းစသည်တို့ကိုလည်း အလွန်ကြိုဆိုပါသည်။

အနည်းဆုံးအားဖြင့် ကျွန်ုပ်တို့၏ tool ကို သင်နှစ်သက်ပါက Github တွင် ကျွန်ုပ်တို့အား star ပေး၍ သင်၏ ထောက်ခံမှုကို ပြသပေးပါ။

## Bug တင်ပြခြင်း

သင်တွေ့ရှိသော မည်သည့် bug ကိုမဆို [ဤနေရာတွင်](https://github.com/Yamato-Security/takajo/issues/new?assignees=&labels=bug&template=bug_report.md&title=%5Bbug%5D) တင်ပြပေးပါ။
ဤ project ကို လက်ရှိတွင် တက်ကြွစွာ ထိန်းသိမ်းနေပြီး တင်ပြလာသော မည်သည့် bug ကိုမဆို ပြုပြင်ရန် ကျွန်ုပ်တို့ ဝမ်းမြောက်ပါသည်။

Hayabusa နှင့်ပတ်သက်၍ မည်သည့်ပြဿနာ (false positive များ၊ bug များ စသည်) ကိုမဆို တွေ့ရှိပါက hayabusa github issues စာမျက်နှာ [ဤနေရာတွင်](https://github.com/Yamato-Security/takajo/issues/new?assignees=&labels=bug&template=bug_report.md&title=%5Bbug%5D) တင်ပြပေးပါ။

Hayabusa rule များနှင့်ပတ်သက်၍ မည်သည့်ပြဿနာ (false positive များ၊ bug များ စသည်) ကိုမဆို တွေ့ရှိပါက hayabusa-rules github issues စာမျက်နှာ [ဤနေရာတွင်](https://github.com/Yamato-Security/hayabusa-rules/issues/new) တင်ပြပေးပါ။

Sigma rule များနှင့်ပတ်သက်၍ မည်သည့်ပြဿနာ (false positive များ၊ bug များ စသည်) ကိုမဆို တွေ့ရှိပါက upstream SigmaHQ github issues စာမျက်နှာ [ဤနေရာတွင်](https://github.com/SigmaHQ/sigma/issues) တင်ပြပေးပါ။
