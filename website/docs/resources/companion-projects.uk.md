# Супутні проєкти

* [EnableWindowsLogSettings](https://github.com/Yamato-Security/EnableWindowsLogSettings) - документація та скрипти для належного увімкнення журналів подій Windows.
* [Hayabusa](https://github.com/Yamato-Security/hayabusa) - генератор хронології для пошуку загроз на основі sigma та швидкої криміналістики журналів подій Windows.
* [Hayabusa Rules](https://github.com/Yamato-Security/hayabusa-rules) - правила виявлення для hayabusa.
* [Hayabusa Sample EVTXs](https://github.com/Yamato-Security/hayabusa-sample-evtx) - зразки файлів evtx для тестування правил виявлення hayabusa/sigma.
* [WELA (Windows Event Log Analyzer)](https://github.com/Yamato-Security/WELA) - аналізатор журналів подій Windows, написаний на PowerShell.
