# योगदान और समर्थन

## योगदान

हम किसी भी प्रकार के योगदान का स्वागत करते हैं। पुल रिक्वेस्ट, नियम निर्माण और नमूना evtx लॉग सबसे अच्छे हैं, लेकिन फ़ीचर अनुरोध, बग की सूचना देना आदि का भी हम स्वागत करते हैं।

कम से कम, यदि आपको हमारा टूल पसंद आए तो कृपया Github पर हमें एक स्टार दें और अपना समर्थन दिखाएं!

## बग सबमिशन

आपको मिलने वाले किसी भी बग को कृपया [यहाँ](https://github.com/Yamato-Security/takajo/issues/new?assignees=&labels=bug&template=bug_report.md&title=%5Bbug%5D) सबमिट करें।
यह प्रोजेक्ट वर्तमान में सक्रिय रूप से अनुरक्षित है और हम रिपोर्ट किए गए किसी भी बग को ठीक करने में प्रसन्न होंगे।

यदि आपको Hayabusa के साथ कोई समस्या (फॉल्स पॉज़िटिव, बग आदि) मिलती है, तो कृपया उन्हें hayabusa github issues पेज पर [यहाँ](https://github.com/Yamato-Security/takajo/issues/new?assignees=&labels=bug&template=bug_report.md&title=%5Bbug%5D) रिपोर्ट करें।

यदि आपको Hayabusa नियमों के साथ कोई समस्या (फॉल्स पॉज़िटिव, बग आदि) मिलती है, तो कृपया उन्हें hayabusa-rules github issues पेज पर [यहाँ](https://github.com/Yamato-Security/hayabusa-rules/issues/new) रिपोर्ट करें।

यदि आपको Sigma नियमों के साथ कोई समस्या (फॉल्स पॉज़िटिव, बग आदि) मिलती है, तो कृपया उन्हें अपस्ट्रीम SigmaHQ github issues पेज पर [यहाँ](https://github.com/SigmaHQ/sigma/issues) रिपोर्ट करें।
