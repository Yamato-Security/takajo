# Yardımcı Projeler

* [EnableWindowsLogSettings](https://github.com/Yamato-Security/EnableWindowsLogSettings) - Windows olay günlüklerini doğru şekilde etkinleştirmek için belgeler ve betikler.
* [Hayabusa](https://github.com/Yamato-Security/hayabusa) - Windows olay günlükleri için sigma tabanlı tehdit avcılığı ve hızlı adli zaman çizelgesi oluşturucu.
* [Hayabusa Rules](https://github.com/Yamato-Security/hayabusa-rules) - hayabusa için tespit kuralları.
* [Hayabusa Sample EVTXs](https://github.com/Yamato-Security/hayabusa-sample-evtx) - hayabusa/sigma tespit kurallarını test etmek için kullanılacak örnek evtx dosyaları.
* [WELA (Windows Event Log Analyzer)](https://github.com/Yamato-Security/WELA) - PowerShell ile yazılmış Windows olay günlükleri analizörü.
