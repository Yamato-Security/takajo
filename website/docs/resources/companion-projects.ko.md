# 관련 프로젝트

* [EnableWindowsLogSettings](https://github.com/Yamato-Security/EnableWindowsLogSettings) - Windows 이벤트 로그를 올바르게 활성화하기 위한 문서 및 스크립트.
* [Hayabusa](https://github.com/Yamato-Security/hayabusa) - Windows 이벤트 로그를 위한 sigma 기반 위협 헌팅 및 빠른 포렌식 타임라인 생성기.
* [Hayabusa Rules](https://github.com/Yamato-Security/hayabusa-rules) - hayabusa용 탐지 규칙.
* [Hayabusa Sample EVTXs](https://github.com/Yamato-Security/hayabusa-sample-evtx) - hayabusa/sigma 탐지 규칙 테스트에 사용할 샘플 evtx 파일.
* [WELA (Windows Event Log Analyzer)](https://github.com/Yamato-Security/WELA) - PowerShell로 작성된 Windows 이벤트 로그 분석기.
