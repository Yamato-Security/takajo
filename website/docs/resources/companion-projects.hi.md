# सहयोगी परियोजनाएँ

* [EnableWindowsLogSettings](https://github.com/Yamato-Security/EnableWindowsLogSettings) - Windows इवेंट लॉग को सही ढंग से सक्षम करने के लिए दस्तावेज़ीकरण और स्क्रिप्ट।
* [Hayabusa](https://github.com/Yamato-Security/hayabusa) - Windows इवेंट लॉग के लिए sigma-आधारित थ्रेट हंटिंग और तेज़ फॉरेंसिक टाइमलाइन जनरेटर।
* [Hayabusa Rules](https://github.com/Yamato-Security/hayabusa-rules) - hayabusa के लिए डिटेक्शन नियम।
* [Hayabusa Sample EVTXs](https://github.com/Yamato-Security/hayabusa-sample-evtx) - hayabusa/sigma डिटेक्शन नियमों के परीक्षण के लिए उपयोग करने हेतु नमूना evtx फ़ाइलें।
* [WELA (Windows Event Log Analyzer)](https://github.com/Yamato-Security/WELA) - PowerShell में लिखा गया Windows इवेंट लॉग के लिए विश्लेषक।
