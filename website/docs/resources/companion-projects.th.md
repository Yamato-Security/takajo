# โปรเจกต์ที่เกี่ยวข้อง

* [EnableWindowsLogSettings](https://github.com/Yamato-Security/EnableWindowsLogSettings) - เอกสารและสคริปต์สำหรับการเปิดใช้งานบันทึกเหตุการณ์ของ Windows อย่างถูกต้อง
* [Hayabusa](https://github.com/Yamato-Security/hayabusa) - เครื่องมือล่าภัยคุกคามที่อิงกับ sigma และเครื่องสร้างไทม์ไลน์การพิสูจน์หลักฐานอย่างรวดเร็วสำหรับบันทึกเหตุการณ์ของ Windows
* [Hayabusa Rules](https://github.com/Yamato-Security/hayabusa-rules) - กฎการตรวจจับสำหรับ hayabusa
* [Hayabusa Sample EVTXs](https://github.com/Yamato-Security/hayabusa-sample-evtx) - ไฟล์ evtx ตัวอย่างสำหรับใช้ทดสอบกฎการตรวจจับของ hayabusa/sigma
* [WELA (Windows Event Log Analyzer)](https://github.com/Yamato-Security/WELA) - เครื่องมือวิเคราะห์บันทึกเหตุการณ์ของ Windows ที่เขียนด้วย PowerShell
