# การมีส่วนร่วมและการสนับสนุน

## การมีส่วนร่วม

เรายินดีรับการมีส่วนร่วมในทุกรูปแบบ Pull request การสร้างกฎ และตัวอย่าง evtx log เป็นสิ่งที่ดีที่สุด แต่คำขอฟีเจอร์ การแจ้งบั๊กให้เราทราบ และอื่น ๆ ก็เป็นที่ยินดียิ่งเช่นกัน

อย่างน้อยที่สุด หากคุณชอบเครื่องมือของเรา โปรดให้ดาวแก่เราบน Github และแสดงการสนับสนุนของคุณ!

## การแจ้งบั๊ก

โปรดแจ้งบั๊กใด ๆ ที่คุณพบ [ที่นี่](https://github.com/Yamato-Security/takajo/issues/new?assignees=&labels=bug&template=bug_report.md&title=%5Bbug%5D)
โปรเจกต์นี้กำลังได้รับการดูแลอย่างต่อเนื่องในปัจจุบัน และเรายินดีที่จะแก้ไขบั๊กใด ๆ ที่ได้รับรายงาน

หากคุณพบปัญหาใด ๆ (false positive บั๊ก และอื่น ๆ) เกี่ยวกับ Hayabusa โปรดรายงานไปยังหน้า github issues ของ hayabusa [ที่นี่](https://github.com/Yamato-Security/takajo/issues/new?assignees=&labels=bug&template=bug_report.md&title=%5Bbug%5D)

หากคุณพบปัญหาใด ๆ (false positive บั๊ก และอื่น ๆ) เกี่ยวกับกฎ Hayabusa โปรดรายงานไปยังหน้า github issues ของ hayabusa-rules [ที่นี่](https://github.com/Yamato-Security/hayabusa-rules/issues/new)

หากคุณพบปัญหาใด ๆ (false positive บั๊ก และอื่น ๆ) เกี่ยวกับกฎ Sigma โปรดรายงานไปยังหน้า github issues ของ SigmaHQ ต้นทาง [ที่นี่](https://github.com/SigmaHQ/sigma/issues)
