# Begleitprojekte

* [EnableWindowsLogSettings](https://github.com/Yamato-Security/EnableWindowsLogSettings) - Dokumentation und Skripte zum korrekten Aktivieren von Windows-Ereignisprotokollen.
* [Hayabusa](https://github.com/Yamato-Security/hayabusa) - Sigma-basierter Threat-Hunting- und schneller Forensik-Timeline-Generator für Windows-Ereignisprotokolle.
* [Hayabusa Rules](https://github.com/Yamato-Security/hayabusa-rules) - Erkennungsregeln für Hayabusa.
* [Hayabusa Sample EVTXs](https://github.com/Yamato-Security/hayabusa-sample-evtx) - Beispiel-evtx-Dateien zum Testen von Hayabusa-/Sigma-Erkennungsregeln.
* [WELA (Windows Event Log Analyzer)](https://github.com/Yamato-Security/WELA) - Analysetool für Windows-Ereignisprotokolle, geschrieben in PowerShell.
