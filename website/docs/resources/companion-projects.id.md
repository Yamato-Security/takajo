# Proyek Pendamping

* [EnableWindowsLogSettings](https://github.com/Yamato-Security/EnableWindowsLogSettings) - dokumentasi dan skrip untuk mengaktifkan log event Windows dengan benar.
* [Hayabusa](https://github.com/Yamato-Security/hayabusa) - generator timeline forensik cepat dan threat hunting berbasis sigma untuk log event Windows.
* [Hayabusa Rules](https://github.com/Yamato-Security/hayabusa-rules) - aturan deteksi untuk hayabusa.
* [Hayabusa Sample EVTXs](https://github.com/Yamato-Security/hayabusa-sample-evtx) - contoh file evtx untuk digunakan dalam menguji aturan deteksi hayabusa/sigma.
* [WELA (Windows Event Log Analyzer)](https://github.com/Yamato-Security/WELA) - penganalisis untuk log event Windows yang ditulis dalam PowerShell.
