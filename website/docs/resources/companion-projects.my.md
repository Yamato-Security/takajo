# တွဲဖက်ပရောဂျက်များ

* [EnableWindowsLogSettings](https://github.com/Yamato-Security/EnableWindowsLogSettings) - Windows event log များကို မှန်ကန်စွာ ဖွင့်ရန်အတွက် စာရွက်စာတမ်းများနှင့် scripts များ။
* [Hayabusa](https://github.com/Yamato-Security/hayabusa) - Windows event log များအတွက် sigma အခြေပြု ခြိမ်းခြောက်မှုရှာဖွေခြင်းနှင့် မြန်ဆန်သော forensics timeline ဖန်တီးကိရိယာ။
* [Hayabusa Rules](https://github.com/Yamato-Security/hayabusa-rules) - hayabusa အတွက် ရှာဖွေတွေ့ရှိမှု စည်းမျဉ်းများ။
* [Hayabusa Sample EVTXs](https://github.com/Yamato-Security/hayabusa-sample-evtx) - hayabusa/sigma ရှာဖွေတွေ့ရှိမှု စည်းမျဉ်းများကို စမ်းသပ်ရန်အသုံးပြုသော နမူနာ evtx ဖိုင်များ။
* [WELA (Windows Event Log Analyzer)](https://github.com/Yamato-Security/WELA) - PowerShell ဖြင့်ရေးသားထားသော Windows event log များအတွက် ခွဲခြမ်းစိတ်ဖြာကိရိယာ။
