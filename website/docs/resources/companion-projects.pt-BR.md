# Projetos Complementares

* [EnableWindowsLogSettings](https://github.com/Yamato-Security/EnableWindowsLogSettings) - documentação e scripts para habilitar corretamente os logs de eventos do Windows.
* [Hayabusa](https://github.com/Yamato-Security/hayabusa) - gerador de linha do tempo para caça a ameaças baseada em sigma e perícia forense rápida para logs de eventos do Windows.
* [Hayabusa Rules](https://github.com/Yamato-Security/hayabusa-rules) - regras de detecção para o hayabusa.
* [Hayabusa Sample EVTXs](https://github.com/Yamato-Security/hayabusa-sample-evtx) - arquivos evtx de exemplo para usar em testes de regras de detecção do hayabusa/sigma.
* [WELA (Windows Event Log Analyzer)](https://github.com/Yamato-Security/WELA) - analisador de logs de eventos do Windows escrito em PowerShell.
