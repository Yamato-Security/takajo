# Contribuição e Suporte

## Contribuição

Adoraríamos qualquer forma de contribuição. Pull requests, criação de regras e amostras de logs evtx são as melhores, mas solicitações de recursos, notificações de bugs, etc... também são muito bem-vindas.

No mínimo, se você gosta da nossa ferramenta, por favor nos dê uma estrela no Github e demonstre seu apoio!

## Envio de Bugs

Por favor, envie quaisquer bugs que você encontrar [aqui.](https://github.com/Yamato-Security/takajo/issues/new?assignees=&labels=bug&template=bug_report.md&title=%5Bbug%5D)
Este projeto está atualmente em manutenção ativa e ficaremos felizes em corrigir quaisquer bugs relatados.

Se você encontrar quaisquer problemas (falsos positivos, bugs, etc...) com o Hayabusa, por favor relate-os na página de issues do github do hayabusa [aqui](https://github.com/Yamato-Security/takajo/issues/new?assignees=&labels=bug&template=bug_report.md&title=%5Bbug%5D).

Se você encontrar quaisquer problemas (falsos positivos, bugs, etc...) com as regras do Hayabusa, por favor relate-os na página de issues do github do hayabusa-rules [aqui](https://github.com/Yamato-Security/hayabusa-rules/issues/new).

Se você encontrar quaisquer problemas (falsos positivos, bugs, etc...) com as regras do Sigma, por favor relate-os na página de issues do github do SigmaHQ upstream [aqui](https://github.com/SigmaHQ/sigma/issues).
