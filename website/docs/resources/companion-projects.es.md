# Proyectos complementarios

* [EnableWindowsLogSettings](https://github.com/Yamato-Security/EnableWindowsLogSettings) - documentación y scripts para habilitar correctamente los registros de eventos de Windows.
* [Hayabusa](https://github.com/Yamato-Security/hayabusa) - generador de líneas de tiempo forenses rápidas y de búsqueda de amenazas basado en sigma para los registros de eventos de Windows.
* [Hayabusa Rules](https://github.com/Yamato-Security/hayabusa-rules) - reglas de detección para hayabusa.
* [Hayabusa Sample EVTXs](https://github.com/Yamato-Security/hayabusa-sample-evtx) - archivos evtx de muestra para usar en las pruebas de las reglas de detección de hayabusa/sigma.
* [WELA (Windows Event Log Analyzer)](https://github.com/Yamato-Security/WELA) - analizador de registros de eventos de Windows escrito en PowerShell.
