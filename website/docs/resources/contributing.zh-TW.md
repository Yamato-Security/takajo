# 貢獻與支援

## 貢獻

我們非常歡迎任何形式的貢獻。Pull request、規則撰寫以及範例 evtx 日誌是最棒的貢獻方式，但功能需求、回報錯誤等等也非常歡迎。

至少，如果您喜歡我們的工具，請在 Github 上給我們一顆星，以表達您的支持！

## 錯誤回報

請在[此處](https://github.com/Yamato-Security/takajo/issues/new?assignees=&labels=bug&template=bug_report.md&title=%5Bbug%5D)回報您發現的任何錯誤。
此專案目前正在積極維護中，我們很樂意修正任何回報的錯誤。

如果您發現 Hayabusa 有任何問題（誤報、錯誤等等），請至 hayabusa github issues 頁面[此處](https://github.com/Yamato-Security/takajo/issues/new?assignees=&labels=bug&template=bug_report.md&title=%5Bbug%5D)回報。

如果您發現 Hayabusa 規則有任何問題（誤報、錯誤等等），請至 hayabusa-rules github issues 頁面[此處](https://github.com/Yamato-Security/hayabusa-rules/issues/new)回報。

如果您發現 Sigma 規則有任何問題（誤報、錯誤等等），請至上游的 SigmaHQ github issues 頁面[此處](https://github.com/SigmaHQ/sigma/issues)回報。
