# 기여 및 지원

## 기여

어떤 형태의 기여라도 환영합니다. 풀 리퀘스트, 규칙 작성, 샘플 evtx 로그가 가장 좋지만 기능 요청, 버그 알림 등도 매우 환영합니다.

최소한, 저희 도구가 마음에 드신다면 Github에서 별을 눌러 지지를 보내주세요!

## 버그 제출

발견하신 버그는 [여기에서](https://github.com/Yamato-Security/takajo/issues/new?assignees=&labels=bug&template=bug_report.md&title=%5Bbug%5D) 제출해 주세요.
이 프로젝트는 현재 활발히 유지보수되고 있으며, 보고된 버그는 기꺼이 수정하겠습니다.

Hayabusa에서 문제(오탐, 버그 등)를 발견하시면 hayabusa github 이슈 페이지 [여기](https://github.com/Yamato-Security/takajo/issues/new?assignees=&labels=bug&template=bug_report.md&title=%5Bbug%5D)에 보고해 주세요.

Hayabusa 규칙에서 문제(오탐, 버그 등)를 발견하시면 hayabusa-rules github 이슈 페이지 [여기](https://github.com/Yamato-Security/hayabusa-rules/issues/new)에 보고해 주세요.

Sigma 규칙에서 문제(오탐, 버그 등)를 발견하시면 상위 SigmaHQ github 이슈 페이지 [여기](https://github.com/SigmaHQ/sigma/issues)에 보고해 주세요.
