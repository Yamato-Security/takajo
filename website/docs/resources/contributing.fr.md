# Contribution et support

## Contribution

Nous serions ravis de recevoir toute forme de contribution. Les pull requests, la création de règles et les exemples de journaux evtx sont les bienvenus, mais les demandes de fonctionnalités, le signalement de bugs, etc. sont également très appréciés.

Au minimum, si vous aimez notre outil, n'hésitez pas à nous donner une étoile sur Github et à montrer votre soutien !

## Signalement de bugs

Veuillez signaler tout bug que vous trouvez [ici.](https://github.com/Yamato-Security/takajo/issues/new?assignees=&labels=bug&template=bug_report.md&title=%5Bbug%5D)
Ce projet est actuellement activement maintenu et nous sommes heureux de corriger tout bug signalé.

Si vous rencontrez des problèmes (faux positifs, bugs, etc.) avec Hayabusa, veuillez les signaler sur la page des issues github de hayabusa [ici](https://github.com/Yamato-Security/takajo/issues/new?assignees=&labels=bug&template=bug_report.md&title=%5Bbug%5D).

Si vous rencontrez des problèmes (faux positifs, bugs, etc.) avec les règles Hayabusa, veuillez les signaler sur la page des issues github de hayabusa-rules [ici](https://github.com/Yamato-Security/hayabusa-rules/issues/new).

Si vous rencontrez des problèmes (faux positifs, bugs, etc.) avec les règles Sigma, veuillez les signaler sur la page des issues github en amont de SigmaHQ [ici](https://github.com/SigmaHQ/sigma/issues).
